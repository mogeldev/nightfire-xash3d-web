Unofficial PC fan port · work in progress

Bringing Nightfire back to life on an open-source engine.

The aim is to run the original 2002 PC version on Xash3D FWGS, a maintained open-source engine, using your own game files. This is an engine port, not a remake or a port of the console game.

View progress FAQ

The project is in active development. More information is coming soon.
Want to play the original today? Try the community patches at nightfirepc.com.
